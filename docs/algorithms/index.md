# 算法

算法不是孤立的技巧集合，而是把模糊问题转成精确状态、约束与操作的训练。

## 学习路线

1. **数据结构语义**：数组、链表、栈、队列、树、图分别擅长表达什么。
2. **模式识别**：双指针、滑动窗口、二分、回溯、动态规划。
3. **工程迁移**：缓存淘汰、任务调度、索引结构、限流与一致性哈希。

## 复盘原则

每篇文章都会回答四个问题：暴力解是什么、关键约束是什么、状态如何表示、复杂度为何成立。
